# Cobblemon Evolution Helper

A client-side Minecraft mod by KingdomForge. See every evolution a Pokémon can take, with a tick or cross for each
requirement and your progress, right on Cobblemon's summary screen.

Minecraft 1.21.1, Cobblemon 1.7.3 to 1.8.x, Fabric (with Fabric API) or NeoForge.

- Modrinth: https://modrinth.com/mod/cobblemon-evolution-helper
- CurseForge: https://www.curseforge.com/minecraft/mc-mods/cobblemon-evolution-helper
